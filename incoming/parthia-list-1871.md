Yes. **“do” is “ditto.”** In the name column it means “same surname as above”; elsewhere it repeats the prior value in that column. Also, the far-right column is almost certainly **“Steerage,”** not “Luggage.”

The ship name looks like **R.M.S. “Parthia”**. A separate Parthia manifest transcription also shows William Watson as master and uses the same manifest column structure, which supports that reading. ([immigrantships.net][1])
